# Работа системы

Цепочка: видео или ссылка в Telegram → нарезка и субтитры → Google Drive → проверка SHA-256 и регистрация роликов → расписание каждого аккаунта → Windows Worker → эмулятор с отдельным прокси → публикация с подтверждённой ссылкой.

В Telegram открой `/panel` или `/start`. Меню показывает контентферму, очередь, аккаунты, ПК, эмуляторы и текущие проблемы. В разделе «Аккаунты» можно добавить аккаунт, выбрать эмулятор, поставить паузу и изменить число публикаций в день. Вход в аккаунт внутри приложения и проверенный сценарий этой версии приложения обязательны. Новый аккаунт добавляется на паузе.

Готовые ролики образуют общий пул. Один ролик резервируется один раз для всей платформы: повтор на другом аккаунте этой же платформы запрещён ограничением базы данных. Тот же ID может использоваться отдельно в Instagram, TikTok и YouTube Shorts. Отменённые и ошибочные задания сохраняют резерв; безопасный повтор выполняется в том же задании. ID используются в именах файлов и учёте, в кадр, заголовок и публичное описание не добавляются.

Временные сбои сохранения, регистрации и доставки автоматически повторяются через 1, 3, 10, 30 и 60 минут. Существующие результаты и квитанции используются повторно; готовое видео не пересоздаётся. После пяти неудач задание требует проверки. Если результат публикации неизвестен, повторной отправки нет: сначала проверяется сам аккаунт.

Состояние ПК обновляется каждые 30 секунд. Проверки эмулятора и TCP/UDP выхода через его прокси выполняются примерно раз в минуту. Устаревшая проверка не означает готовность. Сценарий приложения должен быть проверен для установленной версии. При новом инциденте бот отправляет одно уведомление и затем сообщение о восстановлении; обычные паузы и незавершённая настройка остаются в панели.

`install-worker-startup.ps1` регистрирует задачи текущего пользователя Windows для Appium и Worker после входа. Без `-Live` запускается диагностика. Для публикации нужны `-Live`, `allow_publish = true`, проверенные профили и активный аккаунт. Задачи работают в пользовательском сеансе: после полной перезагрузки Windows нужен вход пользователя. У каждого устройства указывается `proxy_expected_ip`; секреты SOCKS5 остаются в защищённом хранилище. Закреплённый `adb_endpoint` сохраняется, даже если MuMu выдаёт другой порт своей NAT-сети.

На сервере модуль `server/app/telegram_admin/extension.py` устанавливается в существующий Dispatcher контентфермы; второй Telegram poller не запускается. Для отдельного размещения бота этот файл копируется как `telegram_admin_extension.py`, а приватная конфигурация задаётся `TELEGRAM_EXTENSION_CONFIG` либо `content_farm/telegram_admin.json`. В репозитории нет токенов. Отчёт контентфермы отправляется её собственным ключом; панель доступна только с административным ключом сервера.

Разгон аккаунта начинается только после его включения и успешных проверок ПК, эмулятора, прокси и сценария приложения. По календарным дням его часового пояса: 1, 1, 2, затем 3 ролика в день. Пауза не сбрасывает дату старта. До фактической готовности дни не отсчитываются. Личный максимум может уменьшить дневную квоту.

Статистика просмотров появляется только после реального измерения в приложении. Отсутствующие измерения нельзя считать нулём. Подключение TikTok и YouTube требует входа в приложения и проверки сценариев их актуальных версий; наличие программы на эмуляторе само по себе не включает публикации.

### Ролики и очередь в Mini App

Открой «Панель» в боте. В «Медиатеке» нажми «Управлять» рядом с роликом: можно посмотреть файл на Google Диске, изменить название и описание, добавить ролик в очередь на выбранный активный аккаунт. Для постановки доступны только платформы, на которых ролик ещё не использован и не закреплён за другим заданием. Время вводится по Москве; сервер сохраняет дневные лимиты, интервалы и окна публикаций.

В «Очереди отправок» нажми «Управлять» у задания: видны аккаунт, время, состояние, число попыток и пояснение ошибки. Ожидающее задание можно поставить на паузу, перенести или отменить. Для продолжения задания на паузе назначь новое время. Уже начатая публикация завершается исполнителем; задание с неизвестным результатом остаётся заблокированным до проверки аккаунта. Изменение текста ролика не редактирует уже опубликованные подписи и не меняет его постоянный идентификатор.
