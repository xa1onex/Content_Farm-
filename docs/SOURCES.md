# Технические источники

- MuMu ADB manual: https://www.mumuplayer.com/help/win/developers-essentials-manual.html
- Appium Python Client и AppiumClientConfig: https://github.com/appium/python-client
- UiAutomator2 compatibility: https://github.com/appium/appium-uiautomator2-driver
- Зафиксированный driver 4.2.9: https://github.com/appium/appium-uiautomator2-driver/blob/v4.2.9/package.json
- Windows DPAPI CryptProtectData: https://learn.microsoft.com/en-us/windows/win32/api/dpapi/nf-dpapi-cryptprotectdata
- Interactive Task Scheduler principals: https://learn.microsoft.com/en-us/powershell/module/scheduledtasks/new-scheduledtaskprincipal
- PostgreSQL queue locking: https://www.postgresql.org/docs/16/sql-select.html

Использование текущих UI-селекторов приложений не выводится из документации Appium: для них требуется проверка на фактической установленной версии и языке.
